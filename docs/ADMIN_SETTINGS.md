# ตั้งค่าระบบสำหรับ Admin

หน้า `admin/settings/index.php` แบ่งเป็นข้อมูลทั่วไป การรีเฟรชอัตโนมัติ การประมวลผล AI และทางลัดตรวจบริการ

- กดบันทึกเพื่อเปลี่ยนค่าจริง ปุ่มคืนค่าจะยกเลิกเฉพาะการแก้ไขที่ยังไม่บันทึก
- ค่าเดิมที่บันทึกเป็น ค.ศ. จะแสดงเป็น พ.ศ. บนฟอร์ม เมื่อกดบันทึกจึงจัดเก็บเป็น พ.ศ.
- ไม่มีช่องแก้ชื่อระบบในหน้าตั้งค่า การบันทึกค่าอื่นจะรักษาชื่อระบบเดิมไว้
- ปีการศึกษาใช้เป็นปีกลางในคลังโครงงาน ไม่ใช่ปีจบแยกแต่ละโครงงาน ไม่เปลี่ยนรหัสนักศึกษาหรือวันที่ส่งเอกสาร
- เปิด–ปิดการรีเฟรชข้อมูลและแจ้งเตือนอัตโนมัติ ตั้งรอบปกติได้ 10–300 วินาที การโหลดหน้าใหม่และกดดูเองยังทำงาน ไม่หยุดสร้างแจ้งเตือนหรือส่งอีเมล ไม่เปลี่ยนรอบตรวจสถานะระบบหรือคำเชิญเฉพาะทาง
- รอบรีเฟรชมีผลหลังโหลดหน้าใหม่
- ปิดตรวจชื่อซ้ำจะไม่สร้างหรือรับงานใหม่ ผลและคิวเดิมยังอยู่ เปิดอีกครั้งเพื่อประมวลผลคิวเดิมต่อ งานที่เริ่มแล้วอาจจบตามปกติ
- ปิด Risk Score จะหยุดคำนวณรอบถัดไป ผลเดิมยังอยู่และอาจเก่า การเปิดใช้งานยังขึ้นกับ Environment Variables และการเรียก Worker/Cron
- Worker ในเครื่องอ่านค่าที่แคชใหม่เมื่อพ้น 5 วินาที และใช้กับรอบถัดไป
- รูปแบบอนุมัติและธีมเดิมถอดจากฟอร์มเพราะยังไม่มีตัวใช้งานที่เชื่อมค่า ค่าที่จัดเก็บเดิมไม่ถูกลบ
- ใช้หน้าโปรไฟล์สำหรับข้อมูลบัญชี และสถานะระบบสำหรับตรวจบริการ
- ค่าเชื่อมต่อฐานข้อมูล อีเมล และ Cron Secret จัดการผ่าน Vercel Environment Variables หรือ `.env` ของเครื่องพัฒนา ไม่กรอก Secret ในหน้านี้

ตรวจการบันทึกโดยไม่แก้ฐานข้อมูล:

```powershell
C:\xampp\php\php.exe tests\verify-settings.php
```
